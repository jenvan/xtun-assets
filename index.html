为什么放心

该有的都有，不该有的都没有

下面这些不是宣传语，都是默认行为。

不用公网 IP，不用动路由器

是被访问的机器主动连出去的，所以没有端口映射、没有固定 IP 也照样能用。

不碰你的内容，不做中间人

隧道里只搬字节，不会把你的内容解开再重打包；访问 HTTPS 网站时，证书校验仍然发生在你和目标网站之间（TLS 端到端）。

动态码 + 签名登录态

登录要手机上的动态码，连续输错会被限速；一旦换了动态码密钥，所有已登录的设备立刻失效。

可以再叠一层应用层加密

不放心传输链路时打开端到端加密：内容在你的客户端与目标之间加密，中途即使被看到也读不出来。

手机、平板、公司电脑都能用

只要有个现代浏览器就行。还能「安装成应用」，桌面图标点开直接是全屏控制台。

设备清单自动维护

哪台在线、什么时候连过，页面自己更新；不用手工登记，也能一键清掉不再用的记录。

线路会自己挑

网络不稳时可以先扫一遍，挑出当前更快的那条路；之后自动定期重挑，你的操作方式不用改。

中继可以换成自己的

不想依赖第三方时，把中转放到自己的服务器上，家里和公司的配置都不用改。

掉线自己回来

网络抖动、换 Wi-Fi、休眠唤醒都不用手动重启；连接恢复后设备会重新出现在清单里。

想完全自己掌控？把中转放到你的服务器上

默认的中转在 Cloudflare 上，开箱可用。也可以换成一台北双方都够得着的服务器 —— 自己的 VPS、家里的软路由、公司一台常开的机器都行。家里和公司在同一座城市时， 让它来会合少绕一圈，往往更快也更稳。

  • 只改一个地址：已开放的桌面 / 网站 / 终端都不用动，用法完全一样
  • 网页入口也跟着走：设备列表、登录、各个连接页面都由它一起提供，不用另配
  • 不依赖第三方：也可以只跑它一个（不装 Cloudflare），支持自带证书 / nginx 反代
