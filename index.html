已在网关上登录过？双击页面任意处 （手机长按 0.6 秒） → 回到设备列表

正向代理

浏览器 SOCKS5 → 本地中转 → CF 边缘出网。TLS 端到端，不做 MITM。

VNC 远程桌面

外网用浏览器控制家里电脑；noVNC 官方页面，缩放 / 画质 / 剪贴板都在。

RDP 远程桌面

Windows 远程桌面走 RDCleanPath（IronRDP 前端），与 VNC 并存。

HTTP 内网穿透

把内网网站挂到 <设备>.xtun.dev，含 WebSocket 透传。
